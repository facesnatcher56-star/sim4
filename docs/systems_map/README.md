| File | Covers |
|---|---|
| `crime_justice.md` | Every crime, how criminals are caught, court, sentencing, prison, records, player options |
| `business_economy_town.md` | Businesses, jobs and careers, the economy cycle, money and the bank, council, elections, city growth |
| `relationships_family_life.md` | Meeting people, romance to marriage, affairs, gossip, feuds, pregnancy, children, ageing, death, grief, inheritance, heirs |
| `health_hazards_storyteller.md` | Illness and injury, hospital, fire, weather and disasters, home chaos, accidents and cars, the storyteller |
