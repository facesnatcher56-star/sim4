**Task 24 part B (asynchronous sharing) is merged to `main`**, code in this same push. Part C (co-op) stays backlog, so this stays `open`.

- **Household export and import:** a Share window lists player households and townie families. The file has members (name, stage, traits, look, skills, aspiration, up to 5 key memories, career, birthday), relationships among them, parent links, Chronicle lines that mention them and small legacy stats. Import turns each member into a townie with a fresh id; names are kept unless someone in town has them; looks are kept where possible and rerolled with `GeneticsUnique.make_distinct` until distinct from everyone; nobody else in town knows them; news and Chronicle line "The X family moved to town". Limits: 40 townies, 12 imported families.
- **Town export and import:** the file is the save plus the Chronicle lines plus an inbox. Import writes a NEW empty slot and refuses a used one.
- **Gifts and letters:** coins (max 500), an allowlisted object, or a letter (max 500 characters), at most 6 per file, delivered once ("A letter from X was waiting at your mailbox") with a fingerprint in `user://share_seen.json` so reloading can't pay twice.
- **Cards:** a family-history card viewer, `.sim4card` JSON export and a PNG save.
- **Safety (untrusted files):** parse-only, plain file names with the right extension, size checked before reading, version check, unknown fields refused, values rebuilt from known fields and clamped, text stripped of control characters, markup, slashes and `..`, strings pointing at `res://`, `user://` or `../` refuse the whole file, ids never kept. Details in `docs/SHARING.md`.

Tests: `share_household_test`, `share_hostile_test` (oversized, corrupt, array, bad names, path, markup, unknown version or fields, wrong types, NaN, inf, huge or negative numbers, huge arrays, a nesting bomb, gift bounds), `share_town_test`, `share_ui_test`. Verified on the branch's clean worktree rebased onto current main (which includes task 26): `--import` clean, fast tier `---- 106 test files, 0 failed, 233.4 s ----`, `RESULT: PASS` (7 agents still sharing the machine).

Rough edges: town saves are checked at the top level and by a whole-file scan, deeper sub-systems go through the normal loader without per-field schema checks; there is no stored Chronicle yet (news lines are merged back into `Story.news`, capped at 60); imported townies keep skills, aspiration and memories as data only; the PNG save needs a real window; there is no Import entry on the title menu yet (imported towns load through the normal Load button). Shared hooks: `save_load.gd` (a `share` block, no version change), `systems_manager.gd` (`ShareState.reset()`), `pause_menu.gd` (a Share item), `hud.gd` (creates `ShareHub`).
